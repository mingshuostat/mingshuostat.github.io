# Mingshuo Liu's Personal Website

This repository contains the source code for my personal academic website:

<https://mingshuostat.github.io/>

The site is built with [Jekyll](https://jekyllrb.com/) and based on the
[Academic Pages](https://academicpages.github.io/) template.

## Local Preview

To preview the website locally, install the Ruby dependencies and run:

```bash
bundle exec jekyll serve -l -H localhost
```

The site will be available at <http://localhost:4000/>.

## Main Content

- Homepage: `_pages/about.md`
- Publications: `_pages/publications.md`
- Talks: `_pages/talks.md`
- Awards and service: `_pages/awardservice.md`
- Teaching: `_pages/teaching.md`
- Photography: `_pages/photograph.md`

## Notes

Static files such as PDFs can be placed in `files/`, and images can be placed
in `images/`.
